# simulacao_ong
🌱 Plataforma Web para ONGs – Projeto Acadêmico

Este é um projeto completo de desenvolvimento web criado com o objetivo de entregar uma plataforma profissional para ONGs, reunindo conceitos de HTML5, CSS3 avançado, JavaScript moderno, SPA, acessibilidade, responsividade e boas práticas de UI/UX.

O projeto foi desenvolvido como parte da disciplina de Desenvolvimento Web, seguindo requisitos formais e simulando um ambiente real de produção.

📌 Objetivo Geral

Desenvolver uma plataforma web que permita que ONGs:

gerenciem suas atividades,

divulguem projetos,

engajem voluntários,

captem recursos,

e mantenham transparência institucional.

Tudo isso aplicando, de forma integrada, os conceitos estudados nas quatro unidades da disciplina.

🎯 Objetivos Específicos

Utilizar HTML5 semântico para criação de estruturas organizadas e acessíveis.

Desenvolver layout responsivo profissional com CSS3 (Grid, Flexbox e Design System).

Criar experiências dinâmicas com JavaScript moderno.

Implementar Single Page Application (SPA) com manipulação do DOM.

Desenvolver templates JavaScript para conteúdos dinâmicos.

Implementar validação avançada de formulários com feedback ao usuário.

Criar máscaras de input (CPF, telefone e CEP).

Aplicar boas práticas de acessibilidade (WCAG 2.1).

Entregar documentação técnica adequada para ambientes profissionais.
